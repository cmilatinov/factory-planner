# Editor Interactions

Make the blueprint editor feel easier to operate and easier to learn.

## Checklist

- [ ] Make active tool state clearer in the toolbar.
- [ ] Improve route start feedback.
- [ ] Improve route preview feedback.
- [ ] Improve route completion feedback.
- [ ] Revisit marquee selection behavior.
- [ ] Consider left-drag with modifier or an explicit selection mode for marquee selection.
- [ ] Add clearer selected-object affordances.
- [ ] Add or expose rotate action for selected rotatable objects.
- [ ] Add or expose delete action for selected objects.
- [ ] Improve keyboard shortcut discoverability without relying on dense instructional text.
- [ ] Ensure Esc behavior is predictable.
- [ ] Ensure Delete behavior is predictable.
- [ ] Ensure R, V, B, G, P, and W shortcuts remain predictable.
- [ ] Ensure route tools do not interfere with dragging and selection.

## Done Criteria

- Core flows are discoverable from visible UI.
- Keyboard shortcuts accelerate work but are not required to understand the editor.
- Existing e2e editor workflows still pass.
