# Canvas Visual Polish

Improve readability and affordances inside the blueprint canvas.

## Checklist

- [ ] Restore a readable blueprint grid.
- [ ] Improve foundation boundaries and scale cues.
- [ ] Improve machine visuals.
- [ ] Improve selected, hover, drag, and focus states for machines.
- [ ] Improve belt visuals.
- [ ] Improve pipe visuals.
- [ ] Improve wire visuals.
- [ ] Improve splitter, merger, junction, support, pump, and power pole visuals.
- [ ] Make route direction and flow easier to scan.
- [ ] Make stack count and bus lane identity easier to scan.
- [ ] Improve input, output, pipe, and power port markers.
- [ ] Ensure port markers are discoverable without visually overwhelming the canvas.
- [ ] Ensure canvas labels and badges do not overlap at common zoom levels.
- [ ] Check desktop and narrow-panel canvas framing.

## Done Criteria

- Components are visually distinct at normal zoom.
- Routing affordances are visible before and during route creation.
- Selection and warning states are clear without relying only on text.
