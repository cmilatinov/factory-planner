# Agent Instructions

Read these files before making project changes:

- `docs/workflow.md` for branch, commit, PR, staging, and validation rules.
- `docs/tasks.md` for the high-level task index.
- `docs/project-architecture.md` for product purpose, active architecture, and improvement context.

When working on tasks:

- Keep PRs small and tied to the task checklist.
- Update the relevant task checklist as work is completed.
- Use the standard PR body sections from `docs/workflow.md`.
- Do not include agent/tool tags or names in branch names, commits, PR titles, issue titles, or docs.
